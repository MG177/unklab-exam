Baseline — current production

Centered white card on gradient background; welcome headline, large T&C SVG, checkbox, wide START pill.

Pros

  • Simple, one-screen mental model
  • Already built and familiar to students
  • Matches login page visual language

Cons

  • T&C as raster/SVG image — not selectable, not accessible
  • Heavy shadow + legacy fonts (Nunito/Montserrat mix)
  • START button fixed width breaks on narrow screens
  • Checkbox styling diverges from design system

2 · Split panel — brand rail + terms pane

Left column anchors context (KEP / Unklab, student ID); right column is scrollable legal copy with sticky agree + CTA.

Pros

  • Best readability — terms get dedicated space
  • Reinforces “you’re logged in as …” before high-stakes start
  • Sticky footer keeps agree + START visible while scrolling
  • Distinct from login card without a full wizard

Cons

  • Two-column layout needs a mobile stack (brand bar on top)
  • Slightly more CSS than Option 1
  • Left rail content must stay short on small heights

3 · Briefing cards — rules at a glance

Three icon cards summarize duration, conduct, and integrity; expandable terms below; then agree + start.

Pros

  • Students see critical facts before reading legal prose
  • Reduces anxiety — “what am I getting into?” answered upfront
  • Good bridge between playful exam UI and formal consent

Cons

  • More vertical content — may push CTA below fold on short laptops
  • Icon/card row needs careful mobile stacking
  • Duplicate info if terms repeat the cards verbatim

4 · Wizard — scroll-gated multi-step consent

Step 2 shows terms with read progress; Step 3 requires explicit acknowledgments before START unlocks.

Pros

  • Strongest compliance story for high-stakes placement
  • Scroll-to-bottom gate reduces “I didn’t read it” disputes
  • Room for future steps (device check, audio test)

Cons

  • Highest build cost — step state, scroll detection, routing edge cases
  • Extra clicks add friction right before an already stressful exam
  • Overkill if terms are short and proctors handle issues live
